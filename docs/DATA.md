| 文件 | 内容 |
|---|---|

## 四、复核方式

```bash
python3 scripts/make_data_manifest.py   # 重新生成本清单
python3 scripts/recover.py              # 复现验证（含负对照）
```

PDF 原件与其 SHA-256 均可与公示页重新下载的文件比对；若发布方更新了文件，哈希会变化，
此时以公示页现行为准，并在 `data/index.json` 中体现新链接。

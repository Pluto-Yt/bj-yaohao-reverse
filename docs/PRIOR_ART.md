## 二、官方口径与国家标准（逐条核实）

### 1. 官方对算法的表述

- 首都之窗办事问答（两处独立页面，措辞一致）：**第一重随机**——申请编码的产生是随机的；**第二重随机**——摇号基数序号由工作人员在公证下按规则分配、形成摇号池数据库文件并刻盘封存；**第三重随机**——国标「线性同余发生器」的摇号算法。
- 指标系统《办事说明（个人）》进一步写明第三重随机**"基础为国标《GB/T 10111—2008〈随机数的产生及其在产品质量抽样检验中的应用程序〉》中的线性同余发生器（参见国标 GB/T 10111—2008 规范性附录 C）"**。
- 上述表述与本次实测（.NET `System.Random`，Knuth 减法发生器，非 LCG）不一致——这是本次工作提出的、需要官方核证的问题。

### 2. GB/T 10111—2008 本体

- 标准名称：《随机数的产生及其在产品质量抽样检验中的应用程序》（代替 GB/T 10111—1988、GB/T 15500—1995）。
- 结构（据本仓库留档预览 PDF 的目次与前言）：第 4 章"随机抽样的一般程序"；第 5 章"生成随机数的方法"含 **5.1 随机数表法、伪随机数发生器法、扑克牌法**；附录 A 随机数表、附录 B 随机抽样的扑克牌法、**附录 C「产生伪随机数的方法与程序」（第 19 页）**。
- 2008 版相较 1988 版**新增**了随机数表法/伪随机数发生器法/扑克牌法、系统随机抽样、分层随机抽样等。
- 即：**标准规定的是方法集合，不指定唯一参数**；官方口径指向的"附录 C"正是"产生伪随机数的方法与程序"。
- 取证路径（供人工核对）：全国标准信息公共服务平台标准详情 id `71F772D7757FD3A7E05397BE0A0AB82A`；
  国家标准全文公开系统阅读 hcno `4537A8977AFA0B7C06BA8B3782F0481C`。
  **注意：附录 C 正文本次未能机读取得**（阅读器 `c.gb688.cn` 在本环境不可达，本仓库预览 PDF 只含封面/目次/前言/正文首页）。

### 3. 摇号池与"池编码公布"

- 2014-01-02 交通委新闻（原文）："系统中还增加了按照阶梯分配摇号基数序号的功能，**每上升一个阶梯就增加一个摇号基数序号**。申请人登录系统进入用户中心，打开'普通指标摇号池编码公布'即可查询**本人编码**对应的各期摇号基数序号。"
- 《办事说明（个人）》的对应表述（"注 2"）与此一致。
- 因此：**该入口只提供"本人"编码的基数序号查询，而不是完整池文件下载**；第三方无法据此匿名重建整期池映射。
  这修正了并行检索中"可下载完整池文件"的初步推断——**不作为可依赖的核验路径**。
- 对**申请人本人**的价值：可以核对"自己编码在各期对应的基数序号"，配合当期公示即可自行确认是否中签（`scripts/lookup.py` 已可完成同等比对）。

## 四、检索盲区（不能排除什么）

1. **付费/受限文献**：知网、万方全文、学位论文库——仅能检索题录，无法确认是否存在更深入的实现级研究。
2. **GB/T 10111—2008 附录 C 正文**：需人工在国家标准全文公开系统在线阅读（免费、但本环境不可达）。
3. **政府内部材料**：摇号软件的第三方测评报告、验收材料、算法说明、公证机构的现场记录明细——公开渠道未见。
4. **微信公众号生态**：内容不可被通用搜索引擎完整索引，可能存在同类分析文章未被检出。
5. **已删除/下架内容**：2013–2014 年前后的技术帖、论坛讨论（如贴吧、水木等）可能已被清理。
6. **代码托管平台**：GitHub 检索当次受 API 限流影响，只做了少量关键词试探，未穷尽。
7. **非中文资料**：本次以中文来源为主，未系统检索英文/日文文献（相关度预计较低）。
8. 因此不能断言"公开世界不存在同类复现"，只能说：**在本次检索覆盖范围内未发现同类实现级、跨期、可复现的验证工作**。

## 五、结论（公开世界已知 / 未知 / 本次的性质）

- **已知**：摇号流程与制度（申报期、25 日封存、26 日配置、阶梯中签率）；官方口径称第三重随机为"国标线性同余发生器（附录 C）"；2014 年官方曾公布程序、有人反编译出 `Random.Next(...)`；摇号池按申请编码升序排列；申请编码非随机（含注册期号）；系统含"摇号客户端 + 演算"功能。
- **未知（公开渠道）**：现行版本的具体实现与参数；官方口径中"线性同余"与现行实现是否一致；第三方测评结论；完整的"序号 ↔ 申请编码"池映射（仅本人可查）。
- **本次工作的性质**：第一份**不依赖官方公布程序、仅用公示数据、跨 31 期、含负对照**的实现级复现与审计报告；
  它同时确认了 2014 年的反编译结论在 2020–2026 年仍然成立，并首次明确指出官方口径与实测实现的算法族差异。

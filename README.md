# 北京小客车指标摇号：抽取算法的黑箱复现与跨期审计

只用**公开的《配置结果》公示 PDF**（不登录、不接触任何账号或个人数据），反推出北京市小客车指标摇号的抽取算法，并在 2014–2026 年**全部 33 期**（单位 17 期 + 家庭和个人 16 期，合计 189,480 条中签记录）公示上完成可复现验证。

## 一句话结论

摇号抽取等价于：

1. 现场公证抽取的**指标配置种子数**作为 **.NET Framework `System.Random`** 的种子；
2. 循环取 `u = Random.Sample()`，映射 `序号 = floor(u × 池大小) + 1`（池大小 = 公示的「基数序号总数」，单位摇号与 2020 年个人摇号为「有效编码总数」）；
3. 抽到已中签者（序号重复，或其申请编码已中签）就丢弃重抽，直到凑满指标数；
4. 公示表按**抽取顺序**排列。

⚠️ 这条结论**不提供任何预测能力**：种子数是摇号当天 10:00 现场由申请人代表启动摇号机抽球产生的，事前不存在。算法公开的价值在于**任何人都能事后独立核验公示结果**。

## 验证结果

| 类别 | 期数 | 结果 |
|---|---|---|
| 单位摇号 | **17/17** | 中签集合与公示顺序 **100% 精确复现**（含 2014-P1 的 1,300/1,300，以及 266/266、400/400、600/600、800/800） |
| 家庭和个人摇号 | **16/16** | 公示集合 100% 包含于生成流；公示序列是生成流的**严格子序列**；集合重合 99.3%–99.9% |
| 负对照（种子 +1） | 全部 | 重合回落到随机基线（如 2014-P1 个人 186 vs 基线 182、2026-P1 个人 3 vs 基线 1.8），排除巧合 |
| 统计审计（33 期） | 全部 | 均匀性 χ²(10) 2.72–16.48（p 0.057–0.974，全部通过）、无重复、游程与差分检验全部通过 |
| 池构造证据 | 全部 | 中签基数序号 ↔ 申请编码秩相关：单位 **+1.0000**（17/17 期完全单调）、个人 +0.021~+0.690（16/16 期为正）⇒ **摇号池按申请编码升序构造** |

逐期明细见 [`data/verification.json`](data/verification.json)；完整结论、方法、负结果见 [`CONCLUSIONS.md`](CONCLUSIONS.md)；
先行工作（2014 年官方公布程序、2016/2019/2024 年各类分析与复现）见 [`docs/PRIOR_ART.md`](docs/PRIOR_ART.md)。

## 快速开始

```bash
# 依赖：python3（标准库）+ pypdf
python3 -m pip install pypdf

# 一键复现（抓取公示 → 下载 PDF → 解析 → 统计审计 → 复现验证）
bash scripts/run_all.sh

# 只想复现验证（数据已随仓库提供）
python3 scripts/recover.py

# 只想查某期是否中签
python3 scripts/lookup.py 4748111419156              # 查最新一期
python3 scripts/lookup.py 4748111419156 --period 2026-P1 --kind person
python3 scripts/lookup.py --list                     # 列出可查期次
```

## 方法概述

1. **数据管道**：公布栏 31 页 → 各期《配置结果》公示 → PDF 首页的「种子数 / 池大小 / 指标总数」+ 全文中签明细（`crawl.py`、`pipeline.py`）。
2. **方案A 统计审计**：跨 15 期个人摇号的抽样均匀性（χ²(10) 4.7–11.8，p 0.23–0.86）、无重复、相邻差分分布、游程、与申请编码相关性（`audit.py`）。发现一个弱结构：中签基数序号与申请编码秩相关恒为 +0.021~0.039，来源是申请编码含注册期号信息、而摇号池按编码升序构造。
3. **方案B 算法反推**：先按官方口径「国标线性同余发生器」做区间枚举 + 模方程投票（`hunt.py`）、索引空间精确解（`lcg_index.py`）、标准 LCG 参数库与多种映射（`hypotheses.py`）——全部不命中；随后在 `prng_zoo.py` 中判别 20+ 种真实世界的发生器与取值方式，**.NET Framework `Random.Sample()` 一次命中全部单位摇号期**，再扩到个人摇号（`recover.py`）。
4. **反推出方法论意义**：官方口径称采用国标 GB/T 10111 的「线性同余发生器」，实测实现是 .NET 的 Knuth 减法发生器，两者不符——公开资料中没有任何描述现行实现的文档，本仓库是首个仅凭公示数据坐实实现层的证据。

## 数据来源与合规

- 全部数据来自北京市小客车指标调控管理信息系统（`xkczb.jtw.beijing.gov.cn`）**公开发布**的《配置结果》公示 PDF 与办事说明。
- 未尝试登录、未绕过任何认证、未接触任何账号、cookie 或个人隐私数据；不包含任何未公开的个人信息（公示本身即公开中签编码）。
- 单期个人摇号**逐位**完全复现需要「基数序号 → 申请编码」完整摇号池文件，该文件不公开；因此个人摇号验证到「包含 + 严格子序列」层级。
